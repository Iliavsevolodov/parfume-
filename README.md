# SCENT GUIDE — парфюмерный сервис команды Greenway

Мобильная учебно-справочная платформа: подбор ароматов Enjoy Care, каталог и мини-академия для партнёров. **Неофициальный командный проект, не связанный с разработчиками или правообладателями Greenway.**

## Что работает

- Персональный подбор 5 ароматов по предпочтениям и описаниям парфюмерных нот (без недоказанных обещаний).
- Каталог из **83 записей**: 72 аромата из каталога Greenway RU от **07.10.2026** и 11 дополнительных лимитированных ароматов из официальных новостей.
- Поиск по номеру, ноте, артикулу; фильтры по коллекциям и категориям.
- Карточки нот (верх / сердце / база), объёмов, артикулов и **исторических** цен.
- 6 мини-уроков с сохранением отметок прохождения локально в браузере.
- Мобильная адаптация и PWA-кеширование основных файлов.

## Запуск

Приложение не требует npm и сервера API. Для разработки:

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000. Не открывайте `index.html` через `file://` — браузер блокирует загрузку каталога из JSON при таком запуске.

## Архитектура

```text
index.html                    # главная и четыре вкладки
assets/styles.css             # дизайн Premium Editorial Impact
assets/app.js                 # подбор, каталог, карточки и мини-академия
assets/icon.svg               # значок приложения
data/fragrances.json          # 83 карточки и provenance
manifest.webmanifest          # PWA
sw.js                         # офлайн-кеш
docs/ROADMAP.md               # этапы развития
.github/workflows/pages.yml   # публикация в GitHub Pages
```

Источник данных — `data/fragrances.json`; `assets/app.js` загружает его при старте. Для обновления ассортимента меняйте JSON, не JS. Исторические цены не означают текущий ценник или наличие.

## Опубликовать на GitHub Pages

В Settings → Pages выберите **Build and deployment → Source: GitHub Actions**. Workflow `Deploy SCENT GUIDE` публикует статический сайт при изменениях в `main`. После настройки ожидаемый адрес: https://iliavsevolodov.github.io/parfume-/ (до фактической публикации адрес не гарантирован).

## Ограничения MVP

Сервис **не имеет** авторизации, облачного хранения прогресса, CRM, интеграции с онлайн-магазином и синхронизации цен. Подбор является алгоритмическим совпадением по описаниям и нотам и не гарантирует, что аромат понравится. Для точного выбора нужен тест на блоттере и, с согласия клиента, коже.

Сведения о 11 лимитированных ароматах относятся к историческим публикациям; актуальность ассортимента и доступность по регионам не установлены. **Не объявляйте парфюмы аналогами конкретных брендов без источников.**
