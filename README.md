# SCENT GUIDE — Академия ароматов Enjoy Care

**SCENT GUIDE** — самостоятельная авторская платформа для изучения парфюмерии и коллекций Greenway Enjoy Care. Сделана прежде всего для мобильных устройств и командной работы с продуктом.

[Открыть платформу](https://iliavsevolodov.github.io/parfume-/)

## Что внутри

- **32 полноценных урока в 7 разделах.** Теория, конкретные парфюмерные примеры, практическое задание и мини-тест с пояснением к каждому ответу.
- **Итоговая проверка на 18 вопросов** с разбором ошибок и повторной попыткой.
- **Атлас 83 ароматов** Enjoy Care: коллекции Classic, Luxe, Day-to-Day, категории, характеристики, пирамиды, объёмы и артикулы пробников.
- **Подбор по предпочтениям**, семействам, нежелательным нотам и назначению. Это предварительная рекомендация, не гарантия совпадения вкуса.
- **Единая SVG-иконография** (35 локальных иконок), авторский дизайн, адаптация под смартфон.
- **Без аккаунтов, регистрации и паролей.** Выполненные уроки сохраняются локально в текущем браузере, без серверного хранения.
- **PWA**: платформу можно добавить на главный экран; ранее загруженные ресурсы доступны из кеша при поддержке браузером.

## Архитектура

```text
index.html                  интерфейс с тремя разделами
assets/styles.css           компоненты, типографика, оформление
assets/app.js               каталог, алгоритм подбора, уроки, тесты
assets/icons.svg            локальные outline-SVG иконки
assets/icon.svg             иконка приложения
data/academy.json           32 авторских учебных материала
data/fragrances.json        данные 83 карточек ароматов
manifest.webmanifest        параметры PWA
sw.js                       управление офлайн-кешем
.github/workflows/pages.yml автоматическая публикация
```

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000. Для работы каталога и обучения необходим локальный HTTP-сервер, поскольку браузер загружает JSON через `fetch`.

## Редактирование

Материалы академии находятся в `data/academy.json`, а карточки продуктов в `data/fragrances.json`. Тестовый вопрос, объяснение, теория и задание входят в одну запись урока.

У проекта нет панели управления и личных кабинетов. Обновления данных выполняются изменением файлов в репозитории; изменения в ветке `main` автоматически публикуются на GitHub Pages.

## Точность информации

Парфюмерное восприятие индивидуально. Сравнения с другими композициями, стойкость, шлейф и субъективные ощущения не являются гарантированными свойствами для каждого человека. В базе есть лимитированные позиции, и их доступность может отличаться. Перед заказом уточняйте **актуальные цены, состав, условия и наличие** у продавца.

SCENT GUIDE — независимый командный образовательный продукт, не официальный сайт компании Greenway.
