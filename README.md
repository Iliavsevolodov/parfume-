# SCENT GUIDE — Академия ароматов Enjoy Care
**Неофициальный образовательный сервис команды партнёров Greenway** — каталог и подробное самостоятельное обучение парфюмерии без регистрации и личных кабинетов.

## Открыть
[Сайт на GitHub Pages](https://iliavsevolodov.github.io/parfume-/)

## Функции
- **26 полноценных уроков** в 6 разделах: теория, примеры из каталога Enjoy Care, практика, проверочный вопрос и ссылка на тип первоисточника.
- **83 ароматические карточки**, включая 72 позиции из каталога Greenway РФ 07.10.2026 и 11 ранее анонсированных лимитированных выпусков, наличие которых не гарантируется.
- Поиск по номеру/артикулу/нотам, карточки с верхними, средними и базовыми нотами.
- Персональный первичный подбор по семействам и нелюбимым нотам, без недоказанных обещаний.
- Весь сервис работает без аккаунтов. Отметки о пройденных тестах сохраняются **только в localStorage текущего браузера** — это не личный кабинет, не серверная запись.
- Адаптивная вёрстка, мобильная навигация, PWA-кеширование. Новая редакционная эстетика: quiet-luxury perfume editorial.

## Источники и подход
- `data/fragrances.json` — товарные карточки на основе каталога РФ от 07.10.2026 и новостей.
- `data/academy.json` — написанный учебный курс по следующим исходным файлам проекта:
  - `pasted_4.txt` — парфюмерный эфир Greenway Global (Олеся Белянкина): консультации, выбор направлений, блоттеры.
  - `pasted.txt` — эфир Вики Андреевой «Enjoy Care в цифрах»: вовлечение, рассказы о продукте и видео.
  - `pasted_2.txt` и `pasted_3.txt` — полный / сокращённый материал эфира Олеси Белянкиной о парфюмерии и работе с клиентами.
  - `Валерия Михайлова Сетевой пре.txt` — беседа Валерии Михайловой с Олесей Белянкиной: психологические ассоциации, гардероб и сочетания.
  - `pasted_5.txt` — фрагмент эфира о концентрации и ассортименте.
- В курсе **отделены официальные данные, мнения спикеров и общие учебные пояснения**. Заявления о 98–99% сходстве, фиксированной стойкости или доходе **не представлены как доказательства**.
- Эфиры не публикуются целиком; уроки являются авторским учебным изложением с атрибуцией. Сами файлы эфиров хранятся у владельца проекта.

## Файлы
```text
index.html                 Основной интерфейс
assets/styles.css          Редизайн платформы
assets/app.js              Навигация, курс, тесты, подбор и каталог
data/academy.json          26 уроков, практические задания, источники, мини-тесты
data/fragrances.json       83 аромата, исторические цены и подтверждения
manifest.webmanifest       Установка как PWA
sw.js                      Офлайн кеш
.github/workflows/pages.yml Автоматическая публикация GitHub Pages
```

## Локальный запуск
```bash
python3 -m http.server 8000
```
Открыть http://localhost:8000. Использование `file://` не поддерживается: курс и каталог загружаются через `fetch()`.

## Обновление
Правки обучения — в `data/academy.json`, ассортимента — в `data/fragrances.json`. Публикация срабатывает при отправке изменений в `main`. Цены, PV и наличие всегда сверяются с [официальным магазином](https://greenwayglobal.com) перед заказом.

Этот проект не является официальным сайтом Greenway и не использует чужие товарные знаки как знак аффилированности.
